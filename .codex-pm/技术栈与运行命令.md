# 技术栈与运行命令

- Status: 更新（2026-09-02，转型为网页端）
- Notes:
  - Web UI: Vue 3 + Vite（工程位于 `web/`）
  - 路由: Vue Router 4
  - 状态管理: Pinia
  - 发音: 浏览器原生 Web Speech API（开发阶段）；部署阶段可切换 Google TTS
  - 数据: 复用已有 JSON 结构化资源（`content/medical_english_content.json`）
  - PDF 处理: Python `pdfplumber` / `pypdf`，脚本位于 `tools/extract_content.py`
  - 原 iOS 工程: 保留于 `MedicalEnglishPronunciation/`，暂不删除

## 开发命令（在 web/ 目录下执行）

```powershell
cd web
npm install          # 安装依赖
npm run dev          # 启动开发服务器（默认 http://localhost:5173）
npm run build        # 生产构建到 web/dist/
npm run preview      # 预览构建产物
```
